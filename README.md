# EPBC_referral_scrape
Development proposals need to be assessed as to whether the impact is significant under the Environment Protection and Biodiversity Conservation Act 1999. This is done by the proponent submitting their project for assessment to the EPBC Act Public Portal. Projects are Open for Comment by the public for 10 days, and currently there is no automatic notification system so interested parties must manually review each project. This respository contains an automatic tool that searches Open for Comment EPBC referralshttps://epbcpublicportal.environment.gov.au/open-for-comments/ for species (or other search terms) of interest, and creates a task in Asana. The notification can be modified to instead send an email.
